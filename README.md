MoraChord  🎹⚡
MoraChord es una Progressive Web App (PWA) de alto rendimiento y baja latencia desarrollada con la API de Web Audio nativa. Funciona como un sintetizador interactivo, reproductor de acordes modulares y caja de ritmos orientada a la interpretación en vivo y la composición rápida tanto en dispositivos móviles como de escritorio.

🚀 Características Principales
Motor de Audio Robusto: Diseñado con gestión estricta de polifonía (Voice Stealing), limpieza automática de nodos en memoria (disconnect()) y un limitador maestro para evitar saturación digital o ruidos de búfer (fritanga).

Matriz de Acordes Dinámica: Soporte para 16 escalas musicales (occidentales, modos griegos, pentatónicas, exóticas y libres) con análisis armónico real en numeración romana (I-VIII).

Joystick de Modificaciones: Modifica al instante las extensiones armónicas de los acordes (Maj7, Dom7, 9th, sus4, dim, aug, 6th) con un movimiento fluido.

Strumplate Exprés: Superficie táctil de rasgueo vertical de 8 cuerdas para una ejecución natural de arpegios y rasgueos armónicos.

Presets de Instrumentos Variados: Incluye Synth Pad, Cuerdas Sinfónicas, Órgano Hammond, Guitarra Eléctrica con distorsión, Bajo Ácido (303), Chiptune 8-Bit, Cristal Mágico, Laser Sweep, Alienígena FM y un Sintetizador Custom FM totalmente configurable.

Efectos Sincronizados: Delay/Eco dinámico con selector de subdivisión rítmica (1/8 D, 1/8, 1/16, 1/4, 1/8 T) ajustado automáticamente al tempo BPM.

Caja de Ritmos Multiestilo (16 Pasos): Más de 20 patrones rítmicos precargados (Rock, French Touch, Disco/House, Trap, Reggaeton, Cumbia, Salsa, Maqsum árabe, Flamenco, etc.) con editor visual de pasos y sincronización de tempo.

🎛️ Parámetros del Sintetizador
Attack & Release: Control global de la envolvente de amplitud para modelar el nacimiento y la caída de las notas.

Cutoff: Filtro de paso bajo (Lowpass) interactivo con respuesta en tiempo real y resonancia calibrada.

Glide (Portamento): Ajuste de velocidad para el deslizamiento tonal entre notas sucesivas.

Compensación de Agudos: Escalado automático de ganancia en registros altos para equilibrar la percepción auditiva y evitar picos estridentes.

📱 Instalación como PWA (Android / iOS)
MoraChord Pro está optimizada para instalarse directamente desde el navegador:

Abre la aplicación en tu navegador móvil (Chrome, Safari, etc.).

Despliega el menú del navegador y selecciona "Agregar a la pantalla principal" o "Instalar aplicación".

El ícono vectorial adaptable se instalará a sangre completa (sin marcos blancos molestos) y la app se abrirá en modo de pantalla completa (fullscreen).

🛠️ Tecnologías Utilizadas
HTML5 / CSS3: Interfaz moderna basada en variables CSS, diseño adaptable y estética oscura optimizada para rendimiento táctil (touch-action: none).

Vanilla JavaScript & Web Audio API: Procesamiento de audio nativo de bajo nivel sin dependencias externas pesadas, asegurando una latencia mínima ideal para tocar en tiempo real.
